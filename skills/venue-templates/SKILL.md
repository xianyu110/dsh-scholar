# Venue Templates

Formatting scaffolding for manuscripts produced from the read-only Evidence
Ledger (design §4.8). The writer fills argumentation; numbers, tables and
figures come from analysis artifacts only.

## conference-paper (default target)

- Title / Authors (human-verified) / Abstract (≤ 200 words, numbers bound to
  evidence) / 1 Introduction / 2 Related Work (corpus-cited only) /
  3 Method (from contract + code snapshot) / 4 Experiments (from contracts:
  datasets, splits, seeds, metrics) / 5 Results (tables from analysis
  artifacts; figures from chart artifacts) / 6 Limitations (from claim
  limitations) / 7 Conclusion (supported claims only) / References (BibTeX).

## journal

Same skeleton plus: extended Related Work, reproducibility statement
(container digest, data hash, seeds, hardware), and an ethics/data-license
section when the project constraints mention licensing.

## arXiv preprint

Conference skeleton with: PDF/A-friendly LaTeX, a clearly marked
"AI-assisted" disclosure paragraph, and the release bundle id referenced in
the acknowledgements.

## Reviewer checklist (per venue class)

1. Every number in the abstract/results references an analysis artifact.
2. Every citation resolves to a corpus paper with passage support.
3. Tables/figures are generated by the deterministic pipeline.
4. Limitations include compute budget and single-dataset scope when true.
5. AI-usage disclosure present per venue policy.
